# Project Identifier Standard

Status: DRAFT

Use a stable prefix and sequential number of at least three digits for each record. Allocate IDs within each type; do not reuse retired IDs. Reference these IDs across systems. Jira issue keys remain delivery references and do not replace these identifiers.
