# Tool Ownership

Status: DRAFT

| System | Responsibility |
|---|---|
| Jira | Delivery management: work items, acceptance criteria, delivery status and testing/UAT work. |
| Notion | Human-friendly project knowledge, readable BA material and preparation notes. |
| GitHub | Version-controlled source of truth for code, important BA documentation, formal requirements, architecture, technical decisions and tests. |
| Research repository | External evidence supporting project decisions, maintained in the GitHub research directory. |
| Future live application | Product deliverable. |

Link to authoritative records instead of duplicating them. Where records conflict, GitHub version-controlled documentation is authoritative for formal requirements, architecture and technical decisions.

AI analyses, researches, synthesises and drafts. Deterministic software calculates, validates, applies explicit scoring rules, tracks metrics and maintains workflow state. The human BA challenges, interprets, approves and decides. AI outputs are never automatically approved project truth.
